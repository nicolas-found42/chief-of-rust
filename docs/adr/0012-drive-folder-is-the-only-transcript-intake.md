# Drive folder is the only transcript Intake; Fireflies and local adds removed

**Amended by [ADR-0018](0018-shell-holds-credentials-and-durability.md).** The Shell no longer
owns this poll. `intake/drive.ts` belongs to the transcript Module, which polls Drive with
credentials the Shell holds. Every choice below stands — polling over push, `readonly` over
write, the Picker, **Sync now** — as that Module's Intake rather than the Shell's.

Transcripts now come from a single user-selected Google Drive folder polled via `drive.readonly`. Local upload (`POST /api/runs/upload`) and the local-filesystem watch (`chokidar` + `watch-archive`) are deleted, and `FirefliesIntake`, its config/state (`fireflies.enabled/apiKey/pollIntervalMinutes`, `state.fireflies`), and `POST /api/fireflies/sync` are removed — the Drive folder covers meeting-service exports that already land in Drive, so a second poller is unnecessary weight. Previous `upload`/`watch`/`fireflies` Runs are discardable test data and need no legacy read path.

Polling (`drive.files.list` filtered to `"'folderId' in parents and trashed=false"`, deduped by `state.drive.ingestedIds`, default 2 min) was chosen over `drive.changes.watch` push because the app is local-first on `localhost:4317` (ADR-0001) with no public webhook URL, and over Drive write/mutation because `readonly` is minimal scope. The folder is chosen with the Google Picker and stored as `{ folderId, folderName }` in `config.drive`; `drive.enabled` gates polling. When Google is not `connected` or the folder is missing, polling idles and `POST /api/google/check` reports a `drive` surface status, reusing the existing four-state connection model. Text extraction reuses `text/convert.ts` (`SUPPORTED_EXTENSIONS` plus `.jsonc` and `drive.files.export` for native Google Docs); `.json`/`.jsonc` remain strict — `JSON.parse` then `sentencesToText` which requires a non-empty `[{speaker_name, text|sentence}]` array or throws `SOURCE_INVALID` — so `.jsonc` is comment-stripped before parse but not relaxed to wrapped or raw-text shapes. See ADR-0013 for the Picker implementation, its remote-script exception to ADR-0001, the per-pick access token, and the deliberate retention of **Sync now**.
