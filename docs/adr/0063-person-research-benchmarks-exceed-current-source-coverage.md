# Person research benchmarks exceed current source coverage

Person research evaluation is a developer capability using a curated benchmark of public people
with independently checked, dated reference evidence, including information the application cannot
yet source. Expectations describe strong research outcomes rather than reproducing today's output,
so collection limitations remain visible targets for improving search instead of reasons to weaken
the benchmark. Evaluation keeps factual reliability (including identity accuracy), completeness,
meeting-preparation usefulness, and operational reliability separate, without an initial overall
score; honest uncertainty and successful research are distinct outcomes.

Live discovery starts from realistic Identity Signals without access to reference answers or source
lists; a complementary evaluation supplies retained reference documents to isolate attribution,
extraction, and synthesis from discovery. Deterministic source-integrity checks accompany a
separately configured semantic judge whose findings cite the reference and evaluated evidence;
ambiguous judgments remain reviewable, and semantic approval cannot override failed integrity
checks. Comparisons hold the reference version and judge configuration fixed.

The benchmark serves general person research across industries. Reference evidence includes video
transcripts and social material beyond current collection capabilities; software-centric sources
do not define the expected evidence for a person.

The initial collection contains 30 Benchmark People spanning industries, roles, and public
footprints. Coverage is measured against each person's independently researched reference and
reported alongside absolute richness, so sparse public evidence is distinguished from missed
available evidence.

Every user has access to the same source collection regardless of their own industry; any
targeting is based on evidence about the person being researched. Research data sources must
require neither an API key nor payment, including a free tier that requires a key; current
collection limitations remain benchmark gaps rather than reasons to lower reference expectations.
This restriction covers data acquisition, not model inference: research and evaluation retain the
application's configurable LLM providers. The implementation effort includes both the evaluator
and production sourcing expansion, with the benchmark measuring the resulting improvements.

Search combines broad parallel discovery with adaptive batches planned from collected evidence
and unanswered questions. All supported sources remain eligible; initial profession hypotheses
guide ordering without excluding other kinds of work. Sparse results prompt broader exploration
rather than an unsupported declaration of completeness. Source acquisition must also work without
signing in.

Profile creation and enrichment form one continuous research operation that publishes evidence
progressively and keeps working until completion. Routine research must not be split into
budget-limited passes that leave enrichment waiting for a later resumption; the previous proposal
to use that operating model is superseded. Completion requires investigating planned coverage,
accounting for actionable leads, testing further expansion that no longer finds useful evidence,
and publishing the resulting findings and explicit gaps. Temporary failures receive recovery
attempts within that operation; persistent source failures become specific documented gaps while
other research continues. Model-provider failure or application shutdown is an interruption,
not successful completion.

Persistent failures retain structured, stage-specific diagnostics and attempted recovery so
developers can reproduce, classify and mitigate them. Observed facts are distinguished from
suspected causes: an HTTP status alone does not establish why access failed, and an unclassified
failure remains explicitly unknown rather than receiving an invented explanation. Diagnostic
records preserve the application's source-visibility and credential boundaries.
