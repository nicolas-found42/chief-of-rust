4. State / URL / search / render path

  • State: SQLite workspace + durable queue; Run records persist timing/usage/limits.
  • URL: /terminal, /terminal#request-{id}, /terminal#reports, /runs/{id}/diagnostics.
  • Search: SearXNG + Firecrawl behind Source Registry (sources.rs); provider-specific provenance stamped (#62).
  • Render: Askama HTML forms via axum; web.rs shell; carbon.css tokens; htmx for partials.
  • Audit: Jev TypeSafe extracts/verifies; Critical Council (5 perspectives) judges claims.

5. Styles & tokens

Design system: crates/app/static/carbon.css (Carbon foundation, issue #56). Tokens include --cds-accent, --cds-border-subtle, --cds-focus, spacing scale --cds-spacing-01…, tag colors. Dark mode follows prefers-color-scheme where defined.

No styles/tokens.css exists in this repo; this visualizer defines its own local variables to stay self-contained.

6. Build / test / CI path

  • Local: cargo fmt --all -- --check, cargo check --workspace --all-targets --locked, cargo clippy … -D warnings.
  • Tests: cargo nextest run --workspace --locked --profile ci + cargo test --doc.
  • CI: GitHub Actions .github/workflows/ci.yml (fmt, check, clippy, test, image). Image job builds Docker and runs scripts/smoke.py.
  • Container: docker compose build app; boot with LLM_PROVIDER=mock.
