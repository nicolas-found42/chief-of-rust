New here? Here’s how this works ✦
{% if section == "meetings" %}

A meeting, from start to follow-through. Add a meeting and prepare a brief. After the conversation, add its transcript and confirm which meeting it belongs to. Generate a debrief to review the decisions and proposed tasks. You choose which tasks to accept.

{% else if section == "content" %}

From idea to a draft you can shape. Scout an idea or open a project. Add evidence, review an outline, then build a draft. Check its sources and edit it before exporting.

{% else if section == "research" %}

Keep track of something you’re curious about. Add a person or topic to watch, then request a report. Open its sources to check what the report says. YouTube observations show measurements collected on specific dates.

{% else if section == "terminal" %}

Ask a question. Follow the clues. Choose a person or company on the Terminal page to begin. Research runs in the background. Review the report’s sources and limits before relying on its answers.

{% else if section == "tasks" %}

Get one thing off your mind. Write down a task, choose a priority, and add a due date if it helps. Mark it done when you finish. Meeting actions are suggestions until you accept them as tasks.

{% else if section == "runs" %}

A Run is one background job. Queued means it’s waiting. Running means it’s working. Done means a result is ready to inspect. Failed means it stopped: open the job to see the cause, then retry after fixing it. A result still needs your review.

{% else if section == "settings" %}

Make this workspace yours. Set your name and timezone. Connect accounts only for the features you want to use. Tasks work locally. Schedules start off; enable each one when you want it to run automatically.

{% endif %}
